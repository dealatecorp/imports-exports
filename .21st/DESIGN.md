# HarborTrack design context

Use the user-selected FleetTrack reference system: near-white grey background, softly rounded white cards, charcoal navigation selection, bright orange shipping-container imagery, compact sans-serif type. Desktop uses a broad cargo illustration with an inset container card and right-side shipment/capacity panels. Mobile uses a two-column statistic grid, full-width container card, then shipment and capacity panels.

Use actual import/export data and accessible native controls. Keep manual transport checkpoints distinct from live vessel tracking. Original generated truck imagery is stored in public/container-truck.png. The 21st catalog was unavailable during lookup; no catalog component source was reused.
